## 📦 Installation

```bash
git clone https://github.com/872nl/Self-Bot-By-Butizada
cd Self-Bot-By-Butizada
npm install
npm install discord.js-selfbot-v13 figlet
node .
```

---

## 💻 Commands

```text
.ping                 → Shows current ping
.userinfo             → Shows your user information
.serverinfo           → Shows current server information

.purge <amount>       → Deletes your last messages (1-100)

.setstatus <text>     → Changes your custom status

.coinflip             → Flips a coin
.8ball <question>     → Ask the magic 8ball
.roll <max>           → Random number

.spam <msg> <amount>  → Spam a message (max 15)

.snipe                → Shows last deleted message

.ascii <text>         → ASCII art
.uwu <text>           → UwU converter
.reverse <text>       → Reverse text
.spoiler <text>       → Spoiler text

.hack @user           → Fake hacking animation

.help                 → Shows all commands
```
